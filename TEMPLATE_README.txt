FACULTY & STAFF DATA COLLECTION TEMPLATE
========================================

Files Created:
--------------
1. Faculty_Staff_Data_Template_YYYYMMDD.csv
   - Main data collection template
   - Can be opened in Excel, Google Sheets, or any spreadsheet application
   - Contains example row and empty rows for data entry

2. FACULTY_DATA_COLLECTION_GUIDE.md
   - Comprehensive guide with detailed instructions
   - Field-by-field explanations
   - Examples and tips for data entry

3. generate_faculty_template_csv.py
   - Python script to regenerate the template if needed
   - No external dependencies required

Quick Start:
------------
1. Open Faculty_Staff_Data_Template_YYYYMMDD.csv in Excel
2. Review the example row (row 3) to understand the format
3. Fill in data starting from row 4
4. Refer to FACULTY_DATA_COLLECTION_GUIDE.md for detailed instructions

Key Points:
-----------
- Required fields are marked with *
- Use semicolons (;) to separate multiple entries
- Keep related fields in the same order (e.g., course names and codes)
- Save your work frequently

For detailed instructions, see: FACULTY_DATA_COLLECTION_GUIDE.md
